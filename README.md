# TrimUI Brick Ports

This repository contains unofficial ports for the TrimUI Brick and compatible devices. Each port’s requirements and tested devices are described in its release.

## Deep Dungeons of Doom

The port sources are in [`ports/deep-dungeons-of-doom/`](ports/deep-dungeons-of-doom/). The first testing release is being prepared for review and will appear on the [releases page](https://github.com/Hkattelu/TrimUI-Brick-Ports/releases).

You’ll need your own purchased Windows Steam game files to play. The release will explain preparation, device requirements, and the current testing status. Game assets and saves are not included.

Third-party components have their own licenses. See [source and licenses](ports/deep-dungeons-of-doom/portmaster/portable/SOURCE-AND-LICENSES.md) for details.
